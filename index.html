📦 widgetManifest.json

This is the widget manifest that defines the widget's identity, location (Workboard module, Record Detail), and required API permissions. Include this file in your widget ZIP when uploading to Zoho CRM.

{ "uniqueName": "workboard_zia_assistant", "displayName": "Workboard AI Assistant", "version": "1.0.0", "platform": "ZohoCRM", "type": "Custom Widget", "location": [ { "module": "Workboard", "type": "Record Detail", "position": "Custom Button" } ], "permissions": [ "ZohoCRM.modules.workboard.READ", "ZohoCRM.modules.workboard.UPDATE", "ZohoCRM.blueprint.READ", "ZohoZia.assistant.EXECUTE" ], "apiDomain": "https://www.zohoapis.com", "homepage": "index.html" }

📁 Widget File Structure

Upload a ZIP containing these files to Zoho CRM under Setup → Developer Space → Widgets:

zoho-crm-widget/ ├── widgetManifest.json ← Widget metadata & permissions ├── index.html ← Widget UI (AI assistant panel) ├── app.css ← Widget styles └── app.js ← Widget logic (ZOHO SDK + Zia API)

💻 Client Script Deployment

The client-script.js is a Zoho CRM Client Script (not part of the widget ZIP). Deploy it separately via Setup → Developer Space → Client Script with module = Workboard, event = Page Load – Detail. It injects the floating AI icon button on every Workboard record detail page.

File: zoho-crm-widget/client-script.js Deployment: Module → Workboard Event → Page Load – Detail Action → Paste script contents, save & activate After widget upload, update the WIDGET_ID constant in client-script.js to match the Widget ID shown in the Zoho CRM Widgets list.

🔑 Required OAuth Connections

Create these connections under Setup → Developer Space → Connections:

Connection Name : zia_connection Service : Zoho OAuth (Zia) Scope : ZohoZia.assistant.EXECUTE Used by : Widget (app.js) to call Zia AI API Connection Name : crm_connection (auto-available in widgets) Service : Zoho CRM Scope : ZohoCRM.modules.workboard.READ Used by : Widget (app.js) to fetch record & blueprint stage
